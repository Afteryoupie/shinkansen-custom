# Shinkansen Custom

以本機 LLM 翻譯工作流程為主的 Shinkansen 客製分支，包含瀏覽器擴充功能與 LLM watchdog。保留網頁翻譯、雙語對照、YouTube 字幕及 OpenCC 繁簡轉換，調整本機字幕排程、選軌、分段與介面。

目前版本：**2.6.1-custom.20261009**（manifest 數字版本：`2.6.1`）。

## 與原作者版本的差異

原專案為 [jimmysu0309/shinkansen](https://github.com/jimmysu0309/shinkansen)。以下列出此分支維護的客製行為，不代表已逐項比對上游最新版本，也不將繼承的通用功能列為本分支原創。

| 項目 | 本分支的調整 |
| --- | --- |
| 跨分頁翻譯 | `crossTabSticky` 預設關閉，避免開啟多個分頁時自動連鎖送出翻譯請求。 |
| 本機字幕排程 | 本機端點使用字幕佇列及精簡提示詞；停用會與前景字幕競爭的本地全軌背景翻譯 worker，保留播放視窗預翻。 |
| YouTube 選軌 | 人工中文字幕優先，其次人工英文字幕；需要 ASR 自動字幕時選影片原音語言，避免選到配音語言。 |
| 字幕分段 | 長譯文以約 24 字為分段目標，利用標點、空格、詞界與轉折詞選切點；保留來源文字與顯示時間範圍。 |
| Laya 決策模型 | Watchdog 獨立管理 Laya multilingual，透過本機 `/v1/systemone` 協助字幕斷句、翻譯前過濾與翻譯後格式檢查；格式不合時只重試問題段落一次，保留真實對話與型號。 |
| LLM watchdog | 附帶模型管理、按需喚醒、閒置休眠、macOS 選單列、Windows 系統匣與網頁控制台。另有 Apple Foundation Models 整合。 |
| 狀態圖標 | 朝左狗狗：休眠／離線閉眼，準備／載入睜眼閉嘴，處理請求時張嘴。App 本體使用準備表情。 |
| 設定介面 | 提早讀取主題偏好；移除設定頁的 iOS／iPadOS App Store 宣傳按鈕。 |
| 更新來源 | 停用原作者 GitHub Releases 自動檢查及提示，清除舊提示與定時檢查；此分支由使用者自行同步與重新載入。 |

OpenAI 相容端點、Gemini、雙語翻譯與 OpenCC 等支援沿用或擴充既有能力。**資料是否送往外部取決於選用的翻譯引擎及決策 API 網址設定**；使用雲端 API 時，相關文字會送至該服務，並非所有模式都只在本機運算。

## 最近更新

### 2026-10-09 · 字幕過濾與格式修正

- **接上實際翻譯入口**：原先 `evaluateBatch` 已有判斷方法，但翻譯包裝只呼叫本地音效規則。現在逐句字幕及 ASR 編號批次都接上翻譯前決策；音效標籤移除，可靠來源語言已符合目標、純型號或確定不需翻譯的文字保留原文，其餘交給翻譯引擎。不因模型把正常對話判成雜訊就刪除。
- **只檢查輸出格式**：檢查空輸出、段數不符、ASR 編號缺漏／重疊、分隔符、程式碼區塊、JSON 或字幕標記等包裝。Laya 格式分類器只取得輸出與格式要求，不取得原文語意；不評斷錯譯、漏意、數字內容或翻譯品質。
- **一次修正與快取保護**：格式有問題的段落繞過快取重試一次，修正後再檢查；有效輸出才寫入翻譯快取。持續失敗不立即再重試，不把錯位或壞格式字幕當成完成。啟用決策時，人工字幕先等整批檢查完成再顯示。
- **保留時間軸與記錄**：過濾後仍保留原始字幕位置；ASR 音效空列須明確核准，並留作時間邊界。除錯記錄 `Laya subtitle pipeline` 顯示過濾、保留、檢查、修正及未解決的數量。
- **移除說話者箭頭**：清除 YouTube 字幕每行開頭的 `>>` 標記，翻譯輸入與字幕顯示都套用；舊快取譯文帶有箭頭時也會在顯示時移除，句中符號保留。

模型機率尚未校準；不確定或服務失敗時保留本地規則。支援 Gemini、自訂模型及 Google Translate 的字幕入口；Google Translate 的重試是重新請求翻譯，無法加入 LLM 修正提示。更新後重新載入擴充功能並刷新影片頁即可；Watchdog 的 Laya 後端在下次喚醒時讀取新程式，不需重建原生 App。

驗證：76 項 JavaScript 測試通過；46 項 Python 測試中 45 項通過、1 項 Windows 實機剪貼簿測試略過。M3 已以正式 Watchdog、Laya 及翻譯 LLM 實測逐句與 ASR 編號流程，確認音效排除、型號保留、格式修正一次及位置對齊。測試由工具驅動，尚未在瀏覽器全片實播。

### 2026-10-09 · Laya 本機決策模型整合

- **替換 Jev 接口**：新幹線改用本機 Laya multilingual 判斷 ASR 字幕句子邊界，不需 API Key。舊設定會一次性遷移；停用、判斷不明確、逾時或服務失敗時沿用本地規則，保留真實對話及時間軸。
- **獨立模型管理**：網頁控制台、macOS 選單列及 Windows 系統匣新增「決策模型」區塊。Laya 請求會自動喚醒模型，閒置 3 分鐘後卸載，並可獨立手動啟動、休眠或切換自動休眠。
- **分開處理請求**：8080 保持公共入口；翻譯／聊天轉發至 8081，`/v1/systemone` 決策請求轉發至 8082。兩類模型分別管理鎖及使用狀態，決策請求不切換翻譯模型、不進入翻譯佇列；同時使用 GPU 時仍會共享算力與記憶體。
- **離線推論與安裝說明**：加入 Laya 專用 Python 環境依賴、固定模型下載版本及安裝操作說明。支援 `noul`、`choice`、`score`；字幕邊界逐項批次推論，減少整批上下文截斷的影響。模型權重需另外下載，不包含在 Git 儲存庫。

驗證：53 項 JavaScript 測試通過；42 項 Python 測試中 41 項通過、1 項 Windows 實機剪貼簿測試略過；macOS 原生選單編譯及回歸測試通過。M3 Metal 已實測冷啟動、暖機推論、正式字幕決策客戶端、三種問題類型及獨立休眠。模型機率尚未針對字幕校準，Windows 系統匣以模擬介面測試，AMD GPU 推論尚未實機驗證。

詳見 [Laya 決策模型安裝與操作](watchdog/LAYA.md)及[控制台畫面](watchdog/design/laya-dashboard.jpg)。更新後需重新載入擴充功能、刷新影片頁，macOS 原生 App 需重新建置。

### 2026-10-09 · 2.6.1-custom.20261009

- **字幕選軌**：移除「優先英文自動字幕」選項及覆蓋規則。人工中文優先於人工英文，人工英文優先於自動字幕；ASR 依原音語言提示選取，多條 ASR 缺少可靠提示時不任意選第一條。已在英文原文軌時維持選擇；若是 YouTube 自動翻譯軌，切回原文。
- **長字幕分段**：顯示分段目標由 40 字改為約 24 字，優先在自然邊界切開，避免把「很多」等短尾單獨留一段。保留每段至少 1.2 秒的限制；時長不足時減少分段，因此不是任何畫面都保證單行。預設 ASR 提示詞同步調整，使用者已儲存的自訂提示詞不會被強制覆寫。
- **版本與設定頁**：數字版本和顯示版本同步更新；設定頁與彈出頁提早套用主題偏好，處理先深色後淺色的閃爍；停用原作者更新提示並移除設定頁 App Store 宣傳按鈕。
- **狗狗圖標**：macOS 選單列、Windows 圖標資源、App 圖標與控制台統一使用朝左側臉。以 `active_requests` 區分準備與工作，工作時固定張嘴，沒有連續嘴部動畫。

驗證範圍：字幕與選軌 46 項測試、主題與更新行為 5 項測試通過；macOS 原生選單編譯及回歸測試通過；Windows 狀態與圖標切換邏輯以模擬系統匣驗證。截圖中的長句以合成時間軸驗證，尚未實播該影片；Windows 新圖標尚未實機驗證。各平台安裝仍需自行更新，拉取程式碼不等於已部署。

## 安裝與更新擴充功能

1. 開啟 Edge／Chrome 的擴充功能管理頁（`edge://extensions/` 或 `chrome://extensions/`）。
2. 開啟「開發人員模式」，選擇「載入解壓縮項目」。
3. 選取本專案的 **`shinkansen/`** 資料夾。
4. 更新程式碼後，在管理頁按「重新載入」，重新開啟設定頁，並刷新要翻譯的網頁／影片。

本分支不再提示原作者的新版本，請自行同步本儲存庫。同步前先保存自己的未提交修改。

## 本機翻譯設定

| 設定 | 建議值／說明 |
| --- | --- |
| 翻譯引擎 | 自訂模型（OpenAI 相容） |
| Base URL | `http://127.0.0.1:8080/v1`，或自己的本機服務位址 |
| API Key | 依服務要求填寫；本專案 watchdog 可留空 |
| 模型 | 直接連模型服務時使用其模型名稱；經 watchdog 時在 watchdog 選擇實際模型 |
| 最大並發批次 | 本機建議 `1` 或 `2`；儲存設定的預設值仍為 `30`，請按算力調整 |
| 跨分頁連鎖翻譯 | 預設關閉 |

Apple 整合有平台與模型品質限制，請先閱讀 [Apple 翻譯說明](watchdog/APPLE_TRANSLATION.md)。不將 HTTP 成功回應視為翻譯品質保證。

## YouTube 字幕規則

中文目標語言下，優先選擇符合目標的人工中文字幕；只有其他繁簡變體或 `zh` 標記時，交由既有內容偵測與轉換處理。沒有人工中文則翻譯人工英文。兩者皆無時，優先使用可確認的原音人工字幕，再使用原音 ASR。

長譯文分段只調整顯示，不刪減內容；時間切點盡量吸附到來源片段起點。跨語言詞序不同、原始字幕缺少細部時間戳、短句時長不足或播放器太窄時，仍可能換行或出現時間近似。

Laya multilingual 預設接上本機 Watchdog 的 `http://127.0.0.1:8080/v1/systemone`，不需 API Key。舊 Jev 設定會一次性轉換成 Laya；之後的開關與自訂網址會保留。流程為「斷句／過濾 → 翻譯 → 格式檢查 → 必要時修正一次」。正常對話、廣告口播與重複說話都保留，不以模型雜訊判斷直接刪除。輸出檢查只針對格式，不判斷語意對錯。停用、低信心、逾時或服務失敗時沿用本地規則。模型尚未針對字幕校準，機率不代表實際正確率。安裝與操作見 [Laya 決策模型](watchdog/LAYA.md)。

```text
shinkansen/       瀏覽器擴充功能（manifest、背景服務、字幕、設定與彈出頁）
```
