# Shinkansen Custom 🚄（本地 LLM 專用最佳化版）

**Shinkansen Custom** 是一套專為**本地 LLM（llama-server / rapid-mlx / Ollama / 本機推論引擎）**深度最佳化的私密、極速雙語網頁與 YouTube 即時字幕翻譯擴充套件。

本專案由開源 Shinkansen WebExtension 改良而來，剔除所有冗餘展示網站與跨平台開發雜質，保留最純淨的擴充功能本體，並針對「本機推論資源有限」與「跨分頁排隊阻塞」進行了關鍵防爆修復與效能優化。

---

## 🌟 核心客製化亮點

### 1. 🛡️ 跨分頁連鎖翻譯防爆機制 (`crossTabSticky: false`)
- **問題解決**：原版插件在翻譯頁面後，只要點擊連結新開分頁，新分頁都會自動觸發連鎖跟翻。當連續開啟多個分頁時，大量並發請求會瞬間塞滿推論佇列，導致本地 LLM 卡死或延遲暴增。
- **客製修正**：新增 `crossTabSticky` 設定開關並**預設關閉**。現在僅手動翻譯當前分頁，新開分頁不會連鎖跟翻，徹底保護本機 GPU/CPU 運算資源。

### 2. ⚡ 本地推論引擎最佳適配
- **低資源友善**：支援將單次最大並發請求降至 1~2 批次，符合個人主機算力。
- **隨點隨譯**：完美支援 SSE（Server-Sent Events）串流輸出，首字生成極快，無需等待整頁翻譯完畢即可即時閱讀。
- **相容智慧守護與休眠**：可直接配合本機端具備按需喚醒與閒置釋放顯存特性的守護代理運作。

### 3. 🌐 OpenAI 標準相容端點支援
- 支援任意提供標準 `/v1/chat/completions` 的本地服務（如 `http://127.0.0.1:8080/v1` 或 `http://127.0.0.1:11434/v1`）。
- 亦可自由切換至雲端 Gemini API 或自訂外部 API。

## 🚀 快速安裝與使用教學

### 第一步：在瀏覽器中安裝擴充功能

本擴充功能支援所有基於 Chromium 的現代瀏覽器（Microsoft Edge、Google Chrome、Brave、Vivaldi 等）：

1. 打開瀏覽器，在網址列進入擴充功能管理頁面：
   - **Microsoft Edge**：`edge://extensions/`
   - **Google Chrome**：`chrome://extensions/`
2. 開啟頁面上的 **「開發人員模式 (Developer Mode)」** 開關。
3. 點選頂部的 **「載入解壓縮項目 (Load unpacked)」** 按鈕。
4. 選擇本專案內的 **`shinkansen`** 資料夾。
5. 安裝完成後，將瀏覽器工具列上的新幹線圖示 🚄 固定釘選以便隨時使用。

---

### 第二步：插件設定建議（本地 LLM 最佳效能配置）

點擊瀏覽器工具列上的新幹線圖示 🚄，進入設定頁面進行以下配置：

| 設定項目 | 建議數值 / 選項 | 說明 |
| :--- | :--- | :--- |
| **翻譯引擎** | **自訂模型 (OpenAI 相容)** | 走本地端推論，速度極快且 100% 私密 |
| **API URL** | `http://127.0.0.1:8080/v1` | 指向本地端推論服務或守護代理端口 |
| **API Key** | `local`（或任意填寫） | 本地服務器通常不檢驗密鑰 |
| **Model 名稱** | `default`（或對應模型名稱） | 依本機模型名稱填寫（例如 `Hy-MT2-1.8B`） |
| **最大並發批次 (Max Concurrent Batches)** | **`1` 或 `2`** | ⚠️ **強烈建議降至 1~2**（預設 30 是給雲端 API，本地端設太高會造成推論塞車） |
| **跨分頁連鎖翻譯 (Cross-tab Sticky)** | **保持關閉 (預設)** | 避免點開多個分頁時瞬間壓垮本機推論資源 |

## 🎯 功能特色一覽

- **原地排版保留**：直接原地替換網頁文字，完全保留字級、樣式、超連結與圖文排版。
- **雙語對照模式**：支援「單語覆蓋」與「雙語對照」，適合語言學習與術語比對。
- **YouTube 即時字幕翻譯**：精準掛載 YouTube 字幕軌道，支援即時翻譯與中英雙語對照。
- **離線繁簡互轉**：內建 OpenCC 詞庫，繁簡中文轉換直接本地秒轉，無需調用模型。
- **完整私密無日誌**：所有文字推論 100% 在您自己的本機內運算，不經過任何第三方伺服器。
