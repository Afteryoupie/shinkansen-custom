# Shinkansen Custom

以本機 LLM 翻譯工作流程為主的 Shinkansen 客製分支，包含瀏覽器擴充功能與 LLM watchdog。保留網頁翻譯、雙語對照、YouTube 字幕及 OpenCC 繁簡轉換，調整本機字幕排程、選軌、分段與介面。

目前版本：**2.6.1-custom.20261009**（manifest 數字版本：`2.6.1`）。

## 與原作者版本的差異

原專案為 [jimmysu0309/shinkansen](https://github.com/jimmysu0309/shinkansen)。以下列出此分支維護的客製行為，不代表已逐項比對上游最新版本，也不將繼承的通用功能列為本分支原創。

| 項目 | 本分支的調整 |
| --- | --- |
| 跨分頁翻譯 | `crossTabSticky` 預設關閉，避免開啟多個分頁時自動連鎖送出翻譯請求。 |
| 本機字幕排程 | 本機端點使用字幕佇列及精簡提示詞；停用會與前景字幕競爭的本地全軌背景翻譯 worker，保留播放視窗預翻。 |
| YouTube 選軌 | 人工中文字幕優先，其次人工英文字幕；需要 ASR 自動字幕時選影片原音語言，避免選到配音語言。 |
| 字幕分段 | 長譯文以約 24 字為分段目標，利用標點、空格、詞界與轉折詞選切點；保留來源文字與顯示時間範圍。 |
| Jev 整合 | 可選用 Jev 提供字幕邊界判斷；未啟用、低信心或服務失敗時回到本地規則。本機來源過濾保守處理，避免刪掉真實對話或型號。 |
| LLM watchdog | 附帶模型管理、按需喚醒、閒置休眠、macOS 選單列、Windows 系統匣與網頁控制台。另有 Apple Foundation Models 整合。 |
| 狀態圖標 | 朝左狗狗：休眠／離線閉眼，準備／載入睜眼閉嘴，處理請求時張嘴。App 本體使用準備表情。 |
| 設定介面 | 提早讀取主題偏好；移除設定頁的 iOS／iPadOS App Store 宣傳按鈕。 |
| 更新來源 | 停用原作者 GitHub Releases 自動檢查及提示，清除舊提示與定時檢查；此分支由使用者自行同步與重新載入。 |

OpenAI 相容端點、Gemini、雙語翻譯與 OpenCC 等支援沿用或擴充既有能力。**資料是否送往外部取決於選用的翻譯引擎及 Jev 設定**；使用雲端 API 時，相關文字會送至該服務，並非所有模式都只在本機運算。

## 最近更新

### 2026-10-09 · 2.6.1-custom.20261009

- **字幕選軌**：移除「優先英文自動字幕」選項及覆蓋規則。人工中文優先於人工英文，人工英文優先於自動字幕；ASR 依原音語言提示選取，多條 ASR 缺少可靠提示時不任意選第一條。已在英文原文軌時維持選擇；若是 YouTube 自動翻譯軌，切回原文。
- **長字幕分段**：顯示分段目標由 40 字改為約 24 字，優先在自然邊界切開，避免把「很多」等短尾單獨留一段。保留每段至少 1.2 秒的限制；時長不足時減少分段，因此不是任何畫面都保證單行。預設 ASR 提示詞同步調整，使用者已儲存的自訂提示詞不會被強制覆寫。
- **版本與設定頁**：數字版本和顯示版本同步更新；設定頁與彈出頁提早套用主題偏好，處理先深色後淺色的閃爍；停用原作者更新提示並移除設定頁 App Store 宣傳按鈕。
- **狗狗圖標**：macOS 選單列、Windows 圖標資源、App 圖標與控制台統一使用朝左側臉。以 `active_requests` 區分準備與工作，工作時固定張嘴，沒有連續嘴部動畫。

驗證範圍：字幕與選軌 46 項測試、主題與更新行為 5 項測試通過；macOS 原生選單編譯及回歸測試通過；Windows 狀態與圖標切換邏輯以模擬系統匣驗證。截圖中的長句以合成時間軸驗證，尚未實播該影片；Windows 新圖標尚未實機驗證。各平台安裝仍需自行更新，拉取程式碼不等於已部署。

## 安裝與更新擴充功能

1. 開啟 Edge／Chrome 的擴充功能管理頁（`edge://extensions/` 或 `chrome://extensions/`）。
2. 開啟「開發人員模式」，選擇「載入解壓縮項目」。
3. 選取本專案的 **`shinkansen/`** 資料夾。
4. 更新程式碼後，在管理頁按「重新載入」，重新開啟設定頁，並刷新要翻譯的網頁／影片。

本分支不再提示原作者的新版本，請自行同步本儲存庫。同步前先保存自己的未提交修改。

## 本機翻譯設定

| 設定 | 建議值／說明 |
| --- | --- |
| 翻譯引擎 | 自訂模型（OpenAI 相容） |
| Base URL | `http://127.0.0.1:8080/v1`，或自己的本機服務位址 |
| API Key | 依服務要求填寫；本專案 watchdog 可留空 |
| 模型 | 直接連模型服務時使用其模型名稱；經 watchdog 時在 watchdog 選擇實際模型 |
| 最大並發批次 | 本機建議 `1` 或 `2`；儲存設定的預設值仍為 `30`，請按算力調整 |
| 跨分頁連鎖翻譯 | 預設關閉 |

Apple 整合有平台與模型品質限制，請先閱讀 [Apple 翻譯說明](watchdog/APPLE_TRANSLATION.md)。不將 HTTP 成功回應視為翻譯品質保證。

## YouTube 字幕規則

中文目標語言下，優先選擇符合目標的人工中文字幕；只有其他繁簡變體或 `zh` 標記時，交由既有內容偵測與轉換處理。沒有人工中文則翻譯人工英文。兩者皆無時，優先使用可確認的原音人工字幕，再使用原音 ASR。

長譯文分段只調整顯示，不刪減內容；時間切點盡量吸附到來源片段起點。跨語言詞序不同、原始字幕缺少細部時間戳、短句時長不足或播放器太窄時，仍可能換行或出現時間近似。

Jev 是選用功能，需在 YouTube 設定啟用並填入 API Key；會將相關字幕上下文送至 TypeSafe AI。未啟用、低信心或請求失敗時使用本地規則。回歸測試使用模擬 API，不代表外部服務延遲或所有影片品質均已驗證。

## 專案結構

```text
shinkansen/       瀏覽器擴充功能（manifest、背景服務、字幕、設定與彈出頁）
watchdog/         模型守護程式、macOS 選單列、控制台與圖標資源
mac/              macOS App 建置及啟動工具
windows/          Windows 系統匣與啟動工具
backends/         模型後端整合
scripts/          輔助工具
tests/            字幕、介面及模型守護程式回歸測試
```

## 驗證

在儲存庫根目錄執行，不會呼叫真實翻譯 API：

```sh
node --test tests/subtitle-jev.test.mjs tests/subtitle-background.test.mjs tests/subtitle-splitting.test.mjs tests/extension-ui.test.mjs
```

原生選單及平台相關測試另見 [watchdog 設計紀錄](watchdog/design/README.md)。
